# Prime number checker
building a prime number checer
This package is used to check prime numbers..
## Installation
```bash 
npm install <packageName>
```
```bash
npm install 
```
## Usage
```js
const isPrime = require("./index");
const num = 23;
const num2 = 4;
console.log(isprime(num)); //true
console.log(isprime(num2)); //false

```
